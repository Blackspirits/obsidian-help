O Obsidian Web Clipper é uma extensão de navegador gratuita que lhe permite destacar páginas e guardar conteúdo da web no seu cofre.

## Instalar o Web Clipper

Obtenha a extensão Obsidian Web Clipper no diretório oficial do seu navegador:

- [Chrome Web Store](https://chromewebstore.google.com/detail/obsidian-web-clipper/cnjifjpddelmedmihgijeibhnjfabmlf)
	- Para Chrome, Brave, Arc, Orion e outros navegadores baseados em Chromium.
- [Firefox Add-Ons](https://addons.mozilla.org/en-US/firefox/addon/web-clipper-obsidian/)
	- Para Firefox e Firefox Mobile.
- [Safari Extensions](https://apps.apple.com/us/app/obsidian-web-clipper/id6720708363)
	- Para macOS, iOS e iPadOS.
- [Edge Add-Ons](https://microsoftedge.microsoft.com/addons/detail/obsidian-web-clipper/eigdjhmgnaaeaonimdklocfekkaanfme)
	- Para Microsoft Edge.

- [[Capturar páginas web]]
	- Comece a utilizar e aprenda a guardar conteúdo de páginas.
- [[Destacar páginas web|Marcador]]
	- Destaque passagens importantes e selecione os elementos que pretende guardar.
- [[Leitor|Leitor]]
	- Leia páginas web numa vista limpa e sem distrações.
- [[Interpretar páginas web|Intérprete]]
	- Utilize instruções em linguagem natural para capturar e modificar dados numa página.
- [[Resolução de problemas do Web Clipper|Resolução de problemas]]

- [[Obsidian Web Clipper/Modelos|Modelos]]
	- Crie modelos personalizados para sites específicos.
- [[Variáveis]]

- [[Lógica]]
	- Utilize condicionais, ciclos e defina variáveis nos modelos.

## Privacidade

O Obsidian Web Clipper guarda conteúdo localmente no seu cofre do Obsidian e segue a nossa [política de privacidade](https://obsidian.md/privacy). Os seus dados não são recolhidos e não recolhemos quaisquer métricas de utilização. O código é [open source](https://github.com/obsidianmd/obsidian-clipper) e auditável.
