O Obsidian permite-lhe importar facilmente ficheiros HTML individuais e pastas inteiras de ficheiros HTML usando o plugin oficial [[Importador|Importer]]. Isto é útil se quiser guardar websites completos no formato [[Obsidian Flavored Markdown|Markdown]], ou se quiser importar dados de uma ferramenta que exporta para HTML. 

Se estiver a importar notas de uma aplicação específica, poderá querer primeiro consultar a lista de aplicações suportadas pelo [[Importador|plugin Importer]] para verificar se existe um conversor específico que preserve melhor os dados que está a migrar.

## Importar dados HTML para o Obsidian

Necessitará do plugin oficial [[Importador]] do Obsidian, que pode [instalar aqui](obsidian://show-plugin?id=obsidian-importer).

1. Abra **[[Configurações]]**.
2. Vá a **Plugins da comunidade** e [instale o Importer](obsidian://show-plugin?id=obsidian-importer).
3. Ative o plugin Importer.
4. Abra o plugin **Importer** usando a paleta de comandos ou o ícone na barra de ferramentas.
5. Em **Formato do ficheiro**, escolha **HTML (.html).**
6. Selecione a localização dos seus ficheiros ou pastas HTML.
7. Clique em **Importar** e aguarde até a importação estar concluída.
8. Concluído!

### Definições de importação

- **Limite de tamanho dos anexos**: Ignorar a importação de anexos maiores do que o tamanho especificado.
- **Tamanho mínimo da imagem**: Ignorar a importação de imagens menores do que o tamanho especificado em qualquer dimensão. Pode ser usado para ignorar ícones e logótipos.
