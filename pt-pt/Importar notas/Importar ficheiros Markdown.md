O Obsidian usa ficheiros Markdown `.md` como formato principal para notas. Isto torna fácil importar ficheiros Markdown para o Obsidian. Muitas aplicações podem editar ficheiros Markdown ou exportar para este formato.

Existem várias formas de adicionar ficheiros Markdown ao seu cofre do Obsidian:

1. Arraste e largue ficheiros ou pastas para a janela do [[Explorador de ficheiros]]
2. Use o navegador de ficheiros do sistema (por exemplo, o Explorador do Windows ou o Finder no macOS) e mova os seus ficheiros diretamente para a pasta do cofre do Obsidian.

### Converter a partir de outras variantes de Markdown

O Obsidian usa o [[Obsidian Flavored Markdown]]. Algumas aplicações usam sintaxe de Markdown ligeiramente diferente. Pode usar o [[Conversor de formato]] para converter os seus ficheiros para a sintaxe Markdown do Obsidian.
