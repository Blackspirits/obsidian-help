Saiba como expandir o Obsidian com plugins criados pela comunidade. Utilize plugins para adaptar o Obsidian às suas necessidades específicas, como suporte para formatos de ficheiro adicionais ou integração com um serviço de terceiros.

> [!warning] Aviso
> Os plugins da comunidade executam código de terceiros em seu nome que pode ser potencialmente prejudicial. Para saber mais sobre o que a equipa do Obsidian faz para prevenir plugins prejudiciais, consulte [[Segurança de plugins]].

## Explorar plugins da comunidade

1. Abra as **[[Configurações]]**.
2. Selecione **Ativar plugins da comunidade**. Para mais informações, consulte [[Segurança de plugins#Restricted mode|Modo restrito]].
3. Selecione **Explorar** para listar todos os plugins da comunidade disponíveis.

Use a caixa de texto para filtrar plugins pelo nome, autor e descrição.

Também pode explorar os plugins disponíveis no seu browser, acedendo a [obsidian.md/plugins](https://obsidian.md/plugins).

## Instalar um plugin da comunidade

Para instalar um plugin da comunidade, deve primeiro desativar o [[Segurança de plugins#Restricted mode|Modo restrito]].

1. Abra as **[[Configurações]]**.
2. No menu lateral, selecione **Plugins da comunidade**.
3. Selecione **Explorar** para ver os plugins da comunidade disponíveis.
4. Selecione o plugin que pretende instalar.
5. Selecione **Instalar**.

Para usar um plugin instalado, é necessário ativá-lo.

## Ativar um plugin da comunidade

Selecione **Ativar** diretamente após a instalação, ou ative-o a partir da lista de Plugins da comunidade em **[[Configurações]] → Plugins da comunidade → Plugins instalados**.

## Atualizar plugins

Por razões de segurança, os plugins da comunidade não se atualizam automaticamente. Pode atualizar todos os plugins de uma vez ou atualizar plugins individualmente.

Para atualizar todos os plugins:

1. Abra as **[[Configurações]]**.
2. Em **Plugins da comunidade → Plugins atuais**, selecione **Verificar atualizações**.
3. Se houver atualizações disponíveis, selecione **Atualizar tudo**.

Para atualizar um plugin individualmente:

1. Abra as **[[Configurações]]**.
2. Em **Plugins da comunidade → Plugins atuais**, selecione **Verificar atualizações**.
3. Em **Plugins instalados**, selecione **Atualizar** junto ao plugin que pretende atualizar.

## Desinstalar um plugin da comunidade

1. Abra as **[[Configurações]]**.
2. No menu lateral, selecione **Plugins da comunidade**.
3. Em **Plugins instalados**, selecione o ícone do caixote do lixo ![[lucide-trash-2.svg#icon]] junto ao plugin que pretende desinstalar.
4. Selecione **Desinstalar** para confirmar.

## Gerir plugins instalados

Em **[[Configurações]] → Plugins da comunidade → Plugins instalados**, cada plugin tem vários ícones para o gerir:

- **[[Configurações]]** ![[lucide-settings.svg#icon]] — Abrir a página de configurações do plugin, se tiver opções configuráveis.
- **[[Teclas de atalho]]** ![[lucide-plus-circle.svg#icon]] — Definir atalhos de teclado para os comandos do plugin.
- **Financiamento** ![[lucide-heart.svg#icon]] — Ver o URL de financiamento do autor do plugin para apoiar o trabalho dele.
- **Desinstalar** ![[lucide-trash-2.svg#icon]] — Remover o plugin do seu cofre.
- **Alternar** — Ativar ou desativar o plugin sem o desinstalar.

Também pode:

- Selecionar o ícone de **atualização** para recarregar todos os plugins.
- Selecionar o ícone de **pasta** ![[lucide-folder-open.svg#icon]] para abrir a pasta de plugins na sua [[Pasta de configuração|pasta de configuração]].
- Usar a **barra de pesquisa** para filtrar plugins por nome.
