As teclas de atalho são atalhos de teclado personalizáveis para os comandos do Obsidian. Pode atribuir qualquer combinação de teclado para acionar comandos como abrir ficheiros, inserir modelos ou ativar/desativar plugins.

As teclas de atalho são diferentes dos [[Atalhos de edição|atalhos de teclado do sistema]] (como `Ctrl+C` para copiar), que são fornecidos pelo sistema operativo e não podem ser personalizados no Obsidian.

## Ver teclas de atalho

A forma mais rápida de ver a tecla de atalho definida para um comando é encontrar o comando na [[Paleta de comandos]]. Se houver uma tecla de atalho listada para esse comando, está definida.

Também pode ver e gerir todas as teclas de atalho em **[[Configurações]] → Teclas de atalho**.

## Definir uma tecla de atalho

Para adicionar ou modificar uma tecla de atalho:

1. Abra **[[Configurações]] → Teclas de atalho**.
2. Encontre o comando na lista ou utilize o filtro de pesquisa.
3. Selecione o ícone de mais (+) junto ao comando.
4. Prima a combinação de teclado que pretende utilizar.
5. Selecione **Guardar** para confirmar.

Pode atribuir múltiplas combinações de teclas de atalho a um único comando selecionando novamente o ícone de mais (+) após definir a primeira tecla de atalho.

## Remover uma tecla de atalho

Para remover uma tecla de atalho:

1. Abra **[[Configurações]] → Teclas de atalho**.
2. Encontre o comando com a tecla de atalho que pretende remover.
3. Selecione o ícone X junto à combinação de teclado.

## Filtrar teclas de atalho

Para mostrar apenas os comandos que têm teclas de atalho atribuídas, selecione o ícone de filtro em **[[Configurações]] → Teclas de atalho**.

## Esquemas de teclado não-americanos

As teclas de atalho são apresentadas tal como apareceriam num esquema de teclado americano. Mesmo que a combinação apresentada não corresponda ao seu esquema de teclado, a tecla de atalho funcionará com base nas teclas reais que premiu (desde que não altere o seu esquema de teclado).

## Atalhos de teclado predefinidos

Para uma lista completa dos atalhos de teclado predefinidos para edição e navegação, consulte [[Atalhos de edição]].
