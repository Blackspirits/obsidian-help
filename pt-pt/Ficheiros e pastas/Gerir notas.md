Pode gerir ficheiros e pastas de várias formas, usando [[Teclas de atalho]], [[Paleta de comandos|comandos]] ou o [[Explorador de ficheiros]].

## Criar uma nova nota

Para criar um novo ficheiro:

1. Prima `Ctrl+N` (ou `Cmd+N` no macOS).
2. Introduza o nome da nota e depois prima `Enter` para começar a editar a nota.

Também pode criar notas usando o [[Explorador de ficheiros#Create a new note|Explorador de ficheiros]], ou selecionando **Criar nova nota** na [[Paleta de comandos]].

> [!hint] Limitação de caracteres do sistema
> O Obsidian respeitará as limitações de nome de ficheiro do sistema operativo no qual cria a nota. Se planear [[Sincronizar as suas notas entre dispositivos|sincronizar as suas notas entre dispositivos]], certifique-se de que os nomes dos seus ficheiros são [seguros para outros sistemas operativos](https://stackoverflow.com/q/1976007).
^blockquote-system-limitation

## Renomear uma nota

Para renomear uma nota ativa:

1. Selecione o nome da nota no topo do editor (ou prima `F2`).
2. Introduza o novo nome e depois prima `Enter`.

Ao renomear um ficheiro, o Obsidian atualiza automaticamente todos os links para esse ficheiro.

Pode renomear uma nota ou pasta sem a abrir, usando o [[Explorador de ficheiros#Rename a file or folder|Explorador de ficheiros]]

## Eliminar uma nota

Para eliminar uma nota, selecione **Mais opções → Eliminar ficheiro** no canto superior direito de uma nota ativa.

Ou selecione **Eliminar ficheiro atual** na [[Paleta de comandos]].

Também pode eliminar uma nota ou pasta usando o [[Explorador de ficheiros#Delete a file or folder|Explorador de ficheiros]].

> [!note] O que acontece aos ficheiros depois de os eliminar?
> Para alterar o que acontece aos ficheiros eliminados, selecione uma das seguintes opções em **[[Configurações]] → Ficheiros e links**:
>
> - **Lixo do sistema**: Por predefinição, os ficheiros eliminados vão para o lixo do sistema do seu sistema operativo. Para restaurar um ficheiro, use o seu gestor de ficheiros preferido.
> - **Lixo do Obsidian**: Pode enviar os ficheiros eliminados para uma pasta `.trash` no seu cofre.
> - **Eliminar permanentemente**: Os ficheiros são imediatamente eliminados sem qualquer forma de os restaurar.
