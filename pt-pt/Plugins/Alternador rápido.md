O Alternador rápido é um [[Plugins nativos|plugin nativo]] que lhe permite pesquisar e abrir notas utilizando apenas o teclado.

## Abrir o Alternador rápido

Existem várias formas de abrir o Alternador rápido quando está ativo:
- Prima `Ctrl+O` (ou `Cmd+O` no macOS) para abrir o Alternador rápido;
- Na faixa de opções, clique em **Abrir o Alternador rápido** ![[lucide-file-search.svg#icon]];
- No telemóvel, quando não estiver a editar uma nota, toque no ícone de mais no centro inferior da aplicação.

## Abrir uma nota com o Alternador rápido

1. [[#Abrir o Alternador rápido]].
2. Escreva para pesquisar uma nota por nome ou apelido.
3. Navegue até à nota utilizando as teclas de seta.
4. Prima `Enter` para abrir a nota selecionada.

> [!info] 
> A funcionalidade de preenchimento automático muda para um algoritmo de resultados mais simples quando o cofre atinge 10 000 itens, de modo a manter um desempenho ideal da aplicação. 
^search-autocomplete-large

Se o texto não corresponder a nenhuma nota, pode premir `Enter` para criar uma nota com esse nome. Mesmo que o texto corresponda a uma ou mais notas semelhantes, ainda pode criar uma nota com o nome exato premindo `Shift+Enter`.

Pode abrir a nota selecionada num novo separador premindo `Ctrl+Enter` (ou `Cmd+Enter` no macOS).

> [!tip] Alternar entre duas notas
> Se o termo de pesquisa estiver vazio, o Alternador rápido mostra as notas mais recentes. Alterne entre duas notas abrindo o Alternador rápido, premindo a seta para baixo e depois premindo `Enter`.


> [!info] Ficheiros excluídos
> Os ficheiros que correspondam aos seus padrões de [[Configurações#Excluded files|Ficheiros excluídos]] são despriorizados nos resultados do Alternador rápido.
