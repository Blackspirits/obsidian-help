Apresentações é um [[Plugins nativos|plugin nativo]] que lhe permite criar apresentações a partir das suas notas. Para iniciar uma apresentação:

**Menu do ficheiro:**

- Clique com o botão direito no separador de uma nota e clique em **Iniciar apresentação**.

**Paleta de comandos:**

1. Prima `Ctrl+P` (ou `Cmd+P` no macOS) para abrir a [[Paleta de comandos]].
2. Pesquise o comando **Iniciar apresentação**.
3. Prima `Enter` com o comando selecionado para iniciar uma apresentação usando a nota ativa.

Para navegar entre diapositivos, clique nas setas esquerda e direita no canto inferior direito, ou prima as teclas de seta esquerda e direita no teclado.

Também pode avançar para o diapositivo seguinte premindo a barra de espaços.

Para parar a apresentação, prima `Escape` ou clique na cruz no canto superior direito da apresentação.

Pode usar qualquer ficheiro Markdown válido como apresentação. Para separar diapositivos, introduza `---` no início de uma linha rodeada por linhas em branco.

```md
# Apresentações com o plugin Apresentações

Uma demonstração sobre como criar apresentações com o plugin Apresentações.

---

## Formatação

Pode usar formatação Markdown normal, como texto *em itálico* e **a negrito**.

---

## Diapositivos

Use `---` para separar diapositivos.
```
