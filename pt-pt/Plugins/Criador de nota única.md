O Criador de nota única é um [[Plugins nativos|plugin nativo]] que lhe permite criar notas com nomes baseados no tempo, também conhecidas como notas Zettelkasten.

Por exemplo, se criar uma nova nota às 09:45 do dia 1 de janeiro de 2024, o Criador de nota única cria uma nota com `202401010945` como nome. Se já existir uma nota com o mesmo nome, a nova nota usa o próximo carimbo de tempo disponível.

## Criar uma nota única

**Faixa de opções:**

- Na faixa de opções, clique em **Criar nova nota única** ![[obsidian-icon-sheets-in-box.svg#icon]].

**Paleta de comandos:**

1. Prima `Ctrl+P` (ou `Cmd+P` no macOS) para abrir a [[Paleta de comandos]].
2. Pesquise o comando **Criar nova nota única**.
3. Prima `Enter` com o comando selecionado.

## Criar notas únicas a partir de um modelo

Por predefinição, as novas notas únicas estão vazias. Para usar outro ficheiro como modelo:

- Abra as **[[Configurações]]**.
- Na barra lateral, clique em **Plugins nativos → Criador de nota única**.
- Em **Localização do ficheiro de modelo**, introduza o ficheiro que pretende usar como modelo.

Para mais informações sobre como escrever modelos, consulte [[Plugins/Modelos]].
