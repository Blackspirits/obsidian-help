Comandos de barra é um [[Plugins nativos|plugin nativo]] que lhe permite executar comandos no editor escrevendo uma barra oblíqua (`/`) no início de uma linha ou após qualquer espaço em branco.

Para executar um comando usando os Comandos de barra:

1. No editor, escreva uma barra oblíqua (`/`).
2. Introduza o nome do comando que pretende executar para pesquisar na lista de comandos disponíveis.
3. Navegue até ao comando usando as teclas de seta.
4. Prima Enter.

Para sair da pesquisa de Comandos de barra sem invocar um comando, prima `Esc` ou a tecla `Space`.

> [!TIP] Correspondência difusa
> Tal como a [[Paleta de comandos]], os Comandos de barra suportam correspondência difusa, o que lhe permite pesquisar comandos mesmo que não saiba os seus nomes exatos. Por exemplo, escreva "scf" para encontrar o comando **Guardar ficheiro atual**.
