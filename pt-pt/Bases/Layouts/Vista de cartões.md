Cartões é um tipo de [[Vistas|vista]] que pode usar em [[Introdução ao Bases|Bases]].

Selecione ![[lucide-layout-grid.svg#icon]] **Cards** no menu de vistas para apresentar ficheiros numa grelha em estilo de galeria com imagens de capa opcionais.

## Definições

As definições da vista de cartões podem ser configuradas nas [[Vistas#View settings|definições de vista]].

- Tamanho do cartão
- Propriedade de imagem
- Ajuste de imagem
- Proporção da imagem

### Tamanho do cartão

Define a largura de um cartão.

### Propriedade de imagem

Os cartões suportam uma imagem de capa opcional, que é uma [[Propriedades|propriedade]] apresentada como imagem no topo do cartão. A propriedade pode ser qualquer uma das seguintes:

- Uma ligação para um [[Anexos|anexo]] local `"[[link/para/anexo.jpg]]"`
- Uma ligação externa (URL)
- Um código de cor hexadecimal (`#000000`)

### Ajuste de imagem

Se tiver uma propriedade de imagem configurada, esta opção determina como a imagem deve ser apresentada no cartão.

- **Cover:** A imagem preenche a caixa de conteúdo do cartão. Se não couber, a imagem será recortada.
- **Contain:** A imagem é redimensionada até caber na caixa de conteúdo do cartão. A imagem não será recortada.

### Proporção da imagem

A altura da imagem de capa é determinada pela sua proporção. A proporção predefinida é 1:1, o que significa que todas as imagens serão quadradas. Ajuste esta opção para tornar a imagem mais curta ou mais alta.
